# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerability details, credentials or sensitive
environment data in public issues, pull requests or discussions.

For vulnerabilities affecting this repository, use:
https://github.com/fabiotreze/fabiotreze/security/advisories/new

For vulnerabilities in another project, follow the security policy
of the affected repository.

Vulnerabilities in Microsoft products or services must be reported
to the Microsoft Security Response Center:
https://msrc.microsoft.com/create-report

---

## Política de segurança

Não publique detalhes de vulnerabilidades, credenciais ou dados sensíveis
de ambientes em issues, pull requests ou discussões públicas.

Para vulnerabilidades neste repositório, utilize:
https://github.com/fabiotreze/fabiotreze/security/advisories/new

Para vulnerabilidades em outro projeto, siga a política de segurança
do repositório afetado.

Vulnerabilidades em produtos ou serviços Microsoft devem ser reportadas
ao Microsoft Security Response Center:
https://msrc.microsoft.com/create-report
