### 🚀 Projetos em destaque

#### 🛡️ Arc Posture Review

[**Arc Posture Review**](https://github.com/fabiotreze/arc-posture-review) — um kit gratuito de avaliação de segurança, somente leitura, para servidores habilitados pelo Azure Arc e SQL Server habilitado pelo Azure Arc.

- Mais de 60 verificações baseadas no Microsoft Cloud Security Benchmark (v2) e no Cloud Adoption Framework
- Árvores de decisão que abrangem da integração inicial à desativação
- Coletor PowerShell somente leitura, análise local no navegador e plano de ação priorizado com pontuação baseada no modelo do Secure Score do Defender for Cloud
- Suporte a ambientes de grande porte, com limite opcional de máquinas
- Disponível em inglês e português brasileiro

#### ☁️ AzureArcBRTips

[**AzureArcBRTips**](https://github.com/fabiotreze/AzureArcBRTips) — uma coleção em evolução de projetos, workbooks, scripts, templates de implantação e orientações práticas sobre Azure Arc.

Cada projeto possui sua própria documentação, pré-requisitos, instruções de uso e histórico de versões.

**Destaque atual: Arc Agent Support Workbook**

Um workbook do Azure Monitor para analisar servidores habilitados pelo Azure Arc:

- Versões do Connected Machine agent e estimativa de suporte
- Piso de segurança configurável para destacar agents que precisam de atenção
- Elegibilidade e saúde do upgrade automático do agent
- Recomendações do Azure Advisor e conformidade do Azure Policy
- Versões de extensões, cobertura de upgrade automático e problemas operacionais
- Interface e guias em inglês e português brasileiro
- Template de implantação ARM e script de validação em PowerShell

As consultas do workbook são somente leitura; implantar ou salvar o workbook cria ou atualiza um recurso do Azure. As classificações de suporte são estimativas e devem ser conferidas na documentação oficial da Microsoft.

### 📢 Aviso

Este espaço é mantido de forma independente para fins educacionais e experimentais. Não possui afiliação ou endosso da Microsoft ou de qualquer outra organização e não representa documentação oficial.

O conteúdo dos repositórios destina-se ao compartilhamento público. Nunca publique credenciais, dados de clientes ou relatórios confidenciais de ambientes em issues, pull requests ou discussões.

O conteúdo pode ser produzido com apoio de inteligência artificial e é revisado pelo autor. Valide as recomendações na documentação oficial atual, revise scripts e templates antes de executá-los e teste fora de produção.
