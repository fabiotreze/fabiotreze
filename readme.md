### 🚀 Featured projects

#### 🛡️ Arc Posture Review

[**Arc Posture Review**](https://github.com/fabiotreze/arc-posture-review) — a free, read-only security assessment kit for Azure Arc-enabled servers and SQL Server enabled by Azure Arc.

- 60+ checks based on the Microsoft Cloud Security Benchmark (v2) and the Cloud Adoption Framework
- Decision trees from onboarding to decommissioning
- Read-only PowerShell collector, local in-browser analysis and a prioritized action plan scored on the Defender for Cloud Secure Score model
- Scales to large estates with an optional machine limit
- English and Brazilian Portuguese

#### ☁️ AzureArcBRTips

[**AzureArcBRTips**](https://github.com/fabiotreze/AzureArcBRTips) — a growing collection of Azure Arc projects, workbooks, scripts, deployment templates and practical guidance.

Each project includes its own documentation, prerequisites, usage instructions and version history.

**Currently featured: Arc Agent Support Workbook**

An Azure Monitor workbook for reviewing Azure Arc-enabled servers:

- Connected Machine agent versions and estimated support status
- Configurable security floor to highlight agents requiring attention
- Automatic agent upgrade eligibility and health
- Azure Advisor recommendations and Azure Policy compliance
- Extension versions, automatic upgrade coverage and operational issues
- English and Brazilian Portuguese UI and guides
- ARM deployment template and PowerShell validation script

The workbook queries are read-only; deploying or saving the workbook creates or updates an Azure resource. Support classifications are estimates and should be checked against official Microsoft documentation.
